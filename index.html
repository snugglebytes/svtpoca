Install as a webapp

iPhone (Safari): tap the Share icon, then "Add to Home Screen".

Android (Chrome): tap the ⋮ menu, then "Add to Home screen" / "Install app".

Desktop (Chrome/Edge): click the install icon (⊕) in the address bar.

Your data is saved on this device only, so install and open it from the same browser each time.

⚠️ Clear all data

This will permanently delete everything in your tracker — all folders, photocards, tags, wishlist/STBO/duplicate status, and photo templates.
